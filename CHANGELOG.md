# Changelog

## 0.1.0 - Initial public release

- Added Rust workspace with `krcm-core` and `krcm-cli`.
- Added KRCM-SPN v4 legacy container compatibility.
- Added KRCM-SPN v5 container with fixed public header, SIV, transcript authentication, encrypted inner metadata, and segmentation.
- Added deterministic v4 and v5 test vectors.
- Added Rust tests, Python reference tests, fuzz targets, and Criterion benchmarks.
